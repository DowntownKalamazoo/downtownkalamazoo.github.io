# Gift photos

Photos for the Holiday Gift Guide go here. Any size works, including photos straight from a phone. The site
publishes resized copies, not the originals.

Name each photo simply, like `cherris-truffles.jpg`, then add it to its gift in `content/gift-guide.yml`:

    image: files/gifts/cherris-truffles.jpg
    image_alt: A box of nine truffles dusted with cocoa.
